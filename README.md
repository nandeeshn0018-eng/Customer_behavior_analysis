# 📊 Retail Customer Behavior & Shopping Trends Analytics

## 🧭 Overview

This end-to-end data analytics project simulates a corporate-level workflow to analyze retail customer behavior and shopping trends. The project covers the complete data lifecycle—starting from raw data loading and exploratory data analysis (EDA) in Python, performing advanced business queries using SQL, building an interactive Power BI dashboard, documenting findings in a structured report, and designing an executive presentation deck using Gamma.

---

## 📂 Dataset

* **Source:** Retail Customer Behavior & Shopping Trends Dataset
* **Description:** Contains transaction records, customer demographics, item categories, purchase amounts, payment methods, review ratings, and shipping types.

* **Database & Querying:** PostgreSQL / MySQL / SQL Server for business analysis.
* **Visualization:** Power BI for interactive dashboards.
* **Documentation & Presentation:** Microsoft Word / Project Report and [Gamma](https://gamma.app/) for presentation slides.

## 📋 Project Steps

1. **Data Loading & Cleaning (Python):**
* Imported raw datasets, checked for missing values, handled duplicates, and standardized column formats using Pandas.


2. **Exploratory Data Analysis (EDA):**
* Uncovered underlying trends in customer spending habits, preferred product categories, and demographic distributions.


3. **Business Analysis (SQL):**
* Wrote and executed advanced SQL queries (joins, aggregations, subqueries, and window functions) to answer targeted business questions and extract key performance metrics.


4. **Dashboard Creation (Power BI):**
* Designed a clean, dynamic, and interactive dashboard featuring key metrics like total revenue, top-selling categories, and customer segmentation.


5. **Reporting & Presentation:**
* Compiled a comprehensive project report and built a streamlined slide deck via Gamma for executive stakeholders.
